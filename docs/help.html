Installing

Which file do I need?

Most PCs need fmos-x64.exe, the file from the main Download button. To check, open Settings > System > About and look at System type:

  • "x64-based processor": fmos-x64.exe
  • "ARM-based processor": fmos-arm64.exe

Only download FMOS from this website or its GitHub page. The warnings below are fine to get past for this file, because you know where it came from. Do not do that for a copy from anywhere else.

My browser says the file "isn't commonly downloaded"

That is because FMOS is new and few people have downloaded it. It does not mean anything harmful was found.

  • Microsoft Edge: in the downloads list, point at the file, click the ... button, and choose Keep. In the next window, click Show more, then Keep anyway.
  • Other browsers: open the downloads list and look for a Keep button.

Windows says "Windows protected your PC"

This blue window can appear the first time you open FMOS. To open it anyway:

  1. Click More info.
  2. Check that it says App: fmos-x64.exe (or fmos-arm64.exe).
  3. Click Run anyway.

Why Windows warns you: Microsoft Defender SmartScreen warns about downloaded programs that it has not seen many people use and that are not code-signed. Code signing is a paid certificate that tells Windows who made a program. FMOS does not have one yet, so Windows calls it an "Unknown publisher". If the warning appears again, do the same steps.

Windows says Smart App Control blocked FMOS

There is no Run anyway button for this one. Some newer Windows 11 computers block every program that is not code-signed, so FMOS cannot run there yet. Do not turn off Smart App Control just for FMOS. Tell the person who shared FMOS with you instead.

Where should I keep FMOS?

In one of your own folders. Leaving it in Downloads is fine, or you can move it to your Desktop.

Do not put it in C:\Program Files. FMOS updates itself by replacing its own file, and only Administrator programs can change files there.

To open FMOS from the Desktop while the file stays in Downloads, right-click the file and choose Show more options > Send to > Desktop (create shortcut). On Windows 10, choose Send to > Desktop (create shortcut).

Can I use FMOS on a Mac?

Yes, on Macs with Apple Silicon (M1 and newer). FMOS is made for Windows first, so the Mac version does less.

  1. Download fmos-macos.
  2. If macOS says it could not verify that "fmos-macos" is free of malware, click Done, not Move to Trash. macOS blocks downloaded programs that Apple has not checked, and FMOS has not been sent to Apple for checking.
  3. Open Terminal and run:
cd ~/Downloads
chmod +x fmos-macos      # allow it to run as a program
xattr -c fmos-macos      # remove the "downloaded from the internet" block
./fmos-macos

You only need to do this once. For the System panel's details, also install fastfetch with brew install fastfetch.

Using FMOS

FMOS asks for Administrator permissions

Some repairs need Administrator permissions. None of FMOS's current features do, so you will not see this yet.

When a repair needs them, its review screen explains why and offers to restart FMOS as Administrator, but only if you press Y. Windows then dims the screen and asks:

Do you want to allow this app from an unknown publisher to make changes to your device?

fmos-x64.exe
Publisher: Unknown

  • Yes: FMOS closes and opens again as Administrator, on the same review screen. Nothing runs until you press Y there.
  • No: FMOS keeps running without Administrator permissions and tells you which repair it could not run.
  • If your Windows account is not an administrator, Windows asks for an administrator's password instead. If you do not know it, click No.

It says "Unknown publisher" because FMOS is not code-signed yet (see Windows protected your PC).

How do I update FMOS?

You never need to download FMOS again. When a new version comes out, the top line of FMOS says Update available. Choose Updates, read what's new, and press Enter on Update to .... When it is done, quit FMOS and open it again.

FMOS only downloads updates from its GitHub page, checks that the file is intact before using it, and keeps your current version working if anything goes wrong. After an update, you may see a file named fmos-x64.exe.old next to FMOS. That is the previous version, and FMOS deletes it the next time it opens.

How do I send my log to someone helping me?

  1. In FMOS, choose Logs, then press Enter on Open logs folder.
  2. Quit FMOS (press q), so the log is complete.
  3. Send the newest file. Its name has the date and time, for example fmos-2026-10-22_13-45-10.txt.

Logs include details such as your Windows user name, so only send them to people you trust. FMOS never sends logs anywhere by itself.

How do I remove FMOS?

  1. Delete the FMOS file, and fmos-x64.exe.old if there is one. Delete your Desktop shortcut too, if you made one.
  2. To delete the logs as well, press Windows + R, type %LOCALAPPDATA%, press Enter, and delete the FMOS folder there.

That is everything. FMOS adds nothing else to your computer: no Start menu entries, no settings, and nothing that runs in the background.

Safety and privacy

Is FMOS safe?

  • It explains before it changes anything. Each repair shows a review screen first: what it does, the exact command, and whether it needs Administrator permissions, internet, or a restart. Nothing happens until you press Y.
  • It uses Windows' own tools, such as SFC, DISM, and Microsoft Defender, instead of reinventing them.
  • No surprise Administrator prompts. FMOS only asks for Administrator permissions when you choose to.
  • Free and open source. Anyone can read the code on GitHub.

What does FMOS not do?

  • It does not change your computer yet. Repairs are coming, each with its own review screen.
  • It cannot fix every problem, and it does not say something is fixed unless the tool it ran confirms it.
  • It does not run in the background, start with Windows, or install anything else.
  • It is not made by Microsoft.

Does FMOS collect my information?

No. FMOS only goes online to check for updates, and sends nothing about your computer. There is no tracking. Your logs stay on your computer, and sharing one is always your choice.

FMOS is free and open source under the GPL-3.0 license. The code and every release are on GitHub.
