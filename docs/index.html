Fix My OS

FMOS puts common Windows repair and troubleshooting tools in one simple menu, and explains everything in plain English.

Download for Windows

Free. One file, nothing to install. For Windows 10 and 11 on Intel or AMD, which is almost every PC.

What FMOS can do

Lots of useful Windows tools are hidden in settings pages or need commands nobody remembers. FMOS gathers them in one place. It runs the tools Windows already has, shows what they found, and keeps a log you can send to someone helping you.

See your system

Your Windows version, processor, graphics, memory, and free disk space at a glance.

Check your network

Lists your network adapters and addresses, to check your connection or send to someone helping you.

Keep logs for help

Saves a log of everything FMOS did, ready to send to someone helping you from far away.

Update safely

Checks for new versions and updates itself, but only when you choose to.

Coming next: system file and disk repairs (SFC, DISM, CHKDSK), installing and updating apps, driver and Microsoft Store updates, virus scans with Microsoft Defender, and network speed checks.

Safe by design

  • It explains before it changes anything. Each repair shows a review screen first: what it does, the exact command, and whether it needs Administrator permissions, internet, or a restart. Nothing happens until you press Y.
  • It uses Windows' own tools, such as SFC, DISM, and Microsoft Defender, instead of reinventing them.
  • No surprise Administrator prompts. FMOS only asks for Administrator permissions when you choose to.
  • No tracking. FMOS only goes online to check for updates, and sends nothing about your computer.
  • Your logs stay on your computer. Sharing one is always your choice.
  • Free and open source. Anyone can read the code on GitHub.

What FMOS does not do

  • It does not change your computer yet. Repairs are coming, each with its own review screen.
  • It cannot fix every problem, and it does not say something is fixed unless the tool it ran confirms it.
  • It does not run in the background, start with Windows, or install anything else.
  • It is not made by Microsoft.

Installing FMOS on Windows

FMOS is a single program file. There is no installer: you download the file and double-click it. Windows shows a couple of warnings the first time, because FMOS is new. These steps walk you through them.

  1. Download the right file

    Most PCs need the Download for Windows button. Not sure? Open Settings > System > About and look at System type. "x64-based processor" means the main button. "ARM-based processor" means the Windows on ARM file.

    Only download FMOS from this page or its GitHub page. The warnings below are fine to get past for this file, because you know where it came from. Do not do that for a copy from anywhere else.

  2. Keep the file if your browser warns you

    Your browser may say that fmos-x64.exe "isn't commonly downloaded" and hold the file back. That is because FMOS is new and few people have downloaded it. It does not mean anything harmful was found.

    • Microsoft Edge: in the downloads list, point at the file, click the ... button, and choose Keep. In the next window, click Show more, then Keep anyway.
    • Other browsers: open the downloads list and look for a Keep button.

  3. Choose where to keep it

    Keep FMOS in one of your own folders. Leaving it in Downloads is fine, or you can move it to your Desktop.

    Do not put it in C:\Program Files. FMOS updates itself by replacing its own file, and only Administrator programs can change files there.

    To open FMOS from the Desktop while the file stays in Downloads, right-click the file and choose Show more options > Send to > Desktop (create shortcut). On Windows 10, choose Send to > Desktop (create shortcut).

  4. Open FMOS

    Double-click the file. The first time, Windows may show a blue window that says Windows protected your PC. To open FMOS anyway:

    1. Click More info.
    2. Check that it says App: fmos-x64.exe (or fmos-arm64.exe).
    3. Click Run anyway.

    Why Windows warns you: Microsoft Defender SmartScreen warns about programs that it has not seen many people use and that are not code-signed. Code signing is a paid certificate that tells Windows who made a program. FMOS does not have one yet, so Windows calls it an "Unknown publisher". If the warning appears again, do the same steps.

    FMOS opens in a text window. Use the arrow keys to move, Enter to choose, Esc to go back, and q to quit. If the text looks squashed, maximize the window.

    If Windows says Smart App Control blocked FMOS, there is no Run anyway button. Some newer Windows 11 computers block every program that is not code-signed, so FMOS cannot run there yet. Do not turn off Smart App Control just for FMOS. Tell the person who shared FMOS with you instead.

  5. If FMOS asks for Administrator permissions

    Some repairs need Administrator permissions. None of FMOS's current features do, so you will not see this yet.

    When a repair needs them, its review screen explains why and offers to restart FMOS as Administrator, but only if you press Y. Windows then dims the screen and asks:

    Do you want to allow this app from an unknown publisher to make changes to your device?

    fmos-x64.exe
    Publisher: Unknown

    • Yes: FMOS closes and opens again as Administrator, on the same review screen. Nothing runs until you press Y there.
    • No: FMOS keeps running without Administrator permissions and tells you which repair it could not run.
    • If your Windows account is not an administrator, Windows asks for an administrator's password instead. If you do not know it, click No.

    It says "Unknown publisher" for the same reason as the warning in step 4: FMOS is not code-signed yet.

Updating FMOS

You never need to download FMOS again. When a new version comes out, the top line of FMOS says Update available. Choose Updates, read what's new, and press Enter on Update to .... When it is done, quit FMOS and open it again.

FMOS only downloads updates from its GitHub page, checks that the file is intact before using it, and keeps your current version working if anything goes wrong. After an update, you may see a file named fmos-x64.exe.old next to FMOS. That is the previous version, and FMOS deletes it the next time it opens.

Getting help: send your log

If something goes wrong, or someone is helping you from far away, send them your FMOS log:

  1. In FMOS, choose Logs, then press Enter on Open logs folder.
  2. Quit FMOS (press q), so the log is complete.
  3. Send the newest file. Its name has the date and time, for example fmos-2026-10-22_13-45-10.txt.

Logs include details such as your Windows user name, so only send them to people you trust. FMOS never sends logs anywhere by itself.

Removing FMOS

  1. Delete the FMOS file, and fmos-x64.exe.old if there is one. Delete your Desktop shortcut too, if you made one.
  2. To delete the logs as well, press Windows + R, type %LOCALAPPDATA%, press Enter, and delete the FMOS folder there.

That is everything. FMOS adds nothing else to your computer: no Start menu entries, no settings, and nothing that runs in the background.

On a Mac? Download fmos-macos, then follow the Terminal steps in the README.
