What FMOS can do

Lots of useful Windows tools are hidden in settings pages or need commands nobody remembers. FMOS gathers them in one place, runs them for you, and explains what they found.

See your system

Your Windows version, processor, graphics, memory, and free disk space at a glance.

Check your network

Lists your network adapters and addresses, to check your connection or send to someone helping you.

Keep logs for help

Saves a log of everything FMOS did, ready to send to someone helping you from far away.

Update safely

Checks for new versions and updates itself, but only when you choose to.

Coming next: system file and disk repairs (SFC, DISM, CHKDSK), installing and updating apps, driver and Microsoft Store updates, virus scans with Microsoft Defender, and network speed checks.

How to install

There is no installer. FMOS is one file that you download and open.

  1. Download FMOS

    Click Download for Windows above. Keep the file in Downloads or on your Desktop, not in Program Files, so FMOS can update itself.

  2. Keep the file

    If your browser says the file "isn't commonly downloaded", choose Keep. In Edge, click ... next to the file, then Keep, Show more, and Keep anyway.

  3. Open it

    Double-click the file. If Windows says Windows protected your PC, click More info, then Run anyway.

FMOS opens in a text window. Use the arrow keys to move, Enter to choose, Esc to go back, and q to quit.
